# Integrations

This directory contains separately loaded integration examples for Agent Ready
Content. They are not part of the base plugin and are excluded from its release
package.

Each integration is loaded, versioned, and packaged separately. Applications
that use an integration must install or copy it as a separate WordPress plugin.

- [PRC Bridge](prc-bridge/README.md)
  keeps existing PRC Markdown for Agents integrations working with Agent Ready
  Content while those integrations move to the base plugin's native extension
  points.
